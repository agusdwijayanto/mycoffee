1. Cara Pasang di Mac (Herd + DBngin)

Ikuti persis urutan ini. Jangan loncat langkah: php artisan serve adalah langkah terakhir, bukan pertama.

Langkah 1 — Nyalakan MySQL dan buat database

  1. Buka aplikasi DBngin, start service MySQL sampai statusnya jalan.
  2. Buat database kosong bernama mycoffee dari Terminal di VSCode: 
    mysql -h 127.0.0.1 -u root -e "CREATE DATABASE IF NOT EXISTS mycoffee; SHOW DATABASES LIKE 'mycoffee';"
    Kriteria lolos: muncul baris mycoffee. Tambahan -h 127.0.0.1 penting agar koneksi lewat jaringan (TCP), bukan socket.
  3. Bila keluar command not found: mysql, pakai PHP bawaan Herd (hasilnya sama): 
    php -r '$p=new PDO("mysql:host=127.0.0.1;port=3306","root",""); $p->exec("CREATE DATABASE IF NOT EXISTS mycoffee"); echo "mycoffee OK\n";'
  4. Jangan buat tabel apa pun secara manual — semua tabel dibuat oleh migrate.

Langkah 2 — Ekstrak dan pasang project

  1. Ekstrak zip project; isi folder project harus langsung terlihat: file artisan, composer.json, README.md, MANUAL_BOOK.md, dan folder app. Letakkan di folder Herd (misalnya ~/Herd/mycoffee) agar bisa dibuka lewat mycoffee.test.
  2. Buka Terminal di folder project, lalu jalankan: 
    composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
  3. Patokan: composer install tanpa error dan folder vendor terbentuk; key:generate menampilkan Application key set successfully; migrate --seed semua tabel DONE dan berakhir Database seeding completed successfully.
  4. Sesuaikan .env bila setting DBngin berbeda. Bawaan DBngin: DB_HOST=127.0.0.1, DB_PORT=3306, DB_DATABASE=mycoffee, DB_USERNAME=root, DB_PASSWORD= (kosong).

Langkah 3 — Pilihan data

  • Data demo (bawaan, DEMO_DATA=true): terisi 15 transaksi contoh 7 hari terakhir dan 4 pengeluaran contoh — dashboard dan laporan langsung ada isinya. Cocok untuk portofolio.
  • Data bersih: ubah menjadi DEMO_DATA=false di .env SEBELUM migrate --seed. Isinya hanya data pokok (kategori, menu, gallery, pengaturan, akun).

Langkah 4 — Buka aplikasinya

php artisan serve

Buka http://127.0.0.1:8000, atau http://mycoffee.test bila project di folder Herd. Terminal yang menjalankan serve jangan ditutup.

3. Panduan Kasir

Masuk (login)

  • Login email: buka /login, isi email dan password — kasir langsung diarahkan ke POS.
  • Login PIN: buka /login-pin, pilih nama pengguna, masukkan PIN 4 angka. Cocok untuk ganti shift cepat.

Melayani transaksi di POS

  1. Pilih kategori atau cari menu di kolom pencarian.
  2. Makanan dan Dessert: ketuk kartunya sekali — langsung masuk keranjang.
  3. Minuman (Kopi dan Non-Kopi): ketuk kartunya — muncul pop-up opsi: Ukuran (Regular/Large), Level Manis (No/Low/Half/Normal), Level Es (No/Low/Half/Normal), Add-on (extra shot, susu oat, gula aren), Catatan bebas, dan Jumlah — lalu tekan Tambahkan. Pop-up bisa ditutup dengan Batal atau klik di luar kotak tanpa menambah item.
  4. Kombinasi yang sama persis menyatu dalam satu baris; kombinasi berbeda menjadi baris terpisah.
  5. Di keranjang: − / + mengubah jumlah, × menghapus, tombol Ubah membuka pop-up dengan nilai baris itu terisi — simpan untuk mengubah barisnya (bukan menambah baru).
  6. Isi bila perlu: Nama Pelanggan, Nomor Meja, Kanal Penjualan, Diskon %, Kode Voucher.
  7. Metode bayar: Tunai — isi uang bayar; bila kurang, transaksi ditolak dan tidak tersimpan; kembalian dihitung otomatis di struk. QRIS — tampil kotak QR bertuliskan QRIS DUMMY - contoh (bukan kode asli); pembayaran dianggap pas.
  8. Tekan Bayar & Simpan Transaksi. Stok menu dan bahan baku berkurang otomatis. Muncul struk dengan nomor antrean besar — tersedia cetak biasa, Cetak 58mm (thermal), dan Struk Barista.

Di HP, keranjang tampil sebagai bar tetap di bawah layar; ketuk bar itu untuk membuka panel keranjang penuh. Di tablet dan desktop, keranjang menempel di kanan.

Pesanan pending (tahan per meja)

  1. Susun pesanan di keranjang, isi Nomor Meja atau Nama Pelanggan (wajib salah satu).
  2. Tekan Tahan sebagai Pesanan. Pesanan tersimpan pending dan stoknya diamankan (berkurang).
  3. Di menu Pesanan Terbuka: buka kembali untuk menambah item lalu Simpan Perubahan, bayar lewat form bayar biasa, atau batalkan — pembatalan mengembalikan stok.

Shift kasir

  1. Isi modal awal di panel atas POS, tekan Buka Shift (opsional).
  2. Di akhir kerja buka Shift Saya, tutup shift, isi uang fisik di laci.
  3. Sistem menghitung total tunai dan QRIS selama shift dan menampilkan selisih.

Layar barista

Menu Layar Barista menampilkan pesanan terbayar hari ini dalam kolom Baru, Dibuat, Selesai — tekan tombol status untuk memindahkan kartu. Hanya berisi item dan catatan (tanpa harga); versi cetaknya adalah Struk Barista.

Absensi

Di bagian bawah sidebar ada tombol Absen Masuk dan Absen Pulang — satu ketuk mencatat jam hari itu.

4. Panduan Admin

Dashboard dan Laporan

  • Dashboard: omzet hari ini dan bulan ini, jumlah transaksi, menu terlaris, daftar Stok Menipis (batas bawaan 5) dan daftar menu HABIS.
  • Laporan: filter rentang tanggal bebas; omzet, laba kotor (dari harga modal), pengeluaran, laba bersih, omzet per kanal, per metode bayar, per kasir. Tombol Ekspor CSV dan Kirim Rekap via WhatsApp ke nomor pemilik.

Kelola menu, stok, dan bahan

  • Kelola Menu: nama, kategori, deskripsi, harga, tambahan harga Large, harga modal, foto, stok, status aktif. Perubahan stok tercatat di Riwayat Stok.
  • Status HABIS berlaku otomatis bila: stok menu 0, menu dinonaktifkan, atau stok bahan baku resepnya tidak cukup untuk 1 porsi. Menu habis tetap tampil dengan stiker HABIS dan tidak bisa dijual.
  • Bahan Baku: kelola bahan dan resep per menu; penjualan mengurangi stok bahan sesuai takaran; void dan pembatalan mengembalikannya.
  • Menu musiman: isi tanggal tampil dari/sampai agar menu hanya muncul pada rentang itu.
  • Bundel & Add-on: paket dengan satu harga (selisih komponen menjadi diskon otomatis) dan add-on berbayar untuk minuman.

Voucher dan promo

  • Voucher: kode persen atau nominal, tanggal berlaku, status aktif. Contoh bawaan: HEMAT10 (10%) dan NGOPI20 (Rp 20.000). Kode salah/kedaluwarsa ditolak kasir.
  • Beli 2 Gratis 1: pilih menu sasaran di Pengaturan; jumlah menu itu mencapai 3 dalam satu transaksi memberi diskon sebesar 1 harga menu.
  • Voucher, promo, dan diskon persen digabung dalam satu perhitungan dan tercatat di transaksi serta struk.

Void transaksi

Di Riwayat Transaksi → Detail, admin dapat men-void transaksi terbayar dengan alasan wajib. Akibatnya: stok menu dan bahan kembali, transaksi keluar dari semua angka laporan/dashboard, riwayatnya tetap tersimpan berstatus void beserta alasan.

Pengaturan brand

Nama brand, tagline, alamat, telepon, WhatsApp, WhatsApp pemilik, email, jam buka, Instagram, persen pajak, batas stok minimum, dan promo diubah di menu Pengaturan — nama brand langsung tampil di website publik dan panel. Di sini juga ada QR menu (SVG) untuk dicetak dan ditempel di meja.

Testimoni, reservasi, jadwal, pengguna

  • Testimoni: kiriman website menunggu persetujuan sebelum tampil di Beranda.
  • Reservasi: kiriman dari halaman Kontak; ubah status (menunggu/dikonfirmasi/selesai/dibatalkan).
  • Jadwal Karyawan dan Pengguna & PIN untuk kelola jadwal mingguan dan PIN login.

Pengembangan Berikutnya (pratinjau)

5 kartu pratinjau: Multi Cabang, Aplikasi Pelanggan, Payment Gateway Live, Integrasi Akuntansi, Ramalan Penjualan — berlabel besar SEGERA HADIR dengan data contoh DUMMY. Hanya tampilan konsep, belum berfungsi, hanya untuk admin.

  • Buat pesanan pending bernomor meja: muncul di Pesanan Terbuka, stok berkurang.

  • Menu berstok 5 ke bawah muncul di daftar Stok Menipis dashboard (bukan HABIS).

  • Void satu transaksi dengan alasan: omzet laporan berkurang sebesar itu dan stok kembali.
  • Filter laporan rentang lain: angka mengikuti rentang; Ekspor CSV terunduh sesuai rentang.
  • Laporan menampilkan rincian per metode bayar, per kanal, per kasir.
  • Shift: buka shift, 1 transaksi tunai, tutup dengan uang fisik berbeda, selisih terhitung benar.
  • Absensi: Absen Masuk lalu Absen Pulang mencatat jam hari ini.
  • Reservasi dari halaman Kontak muncul di panel admin.

6. Pemecahan Masalah

Failed opening required .../vendor/autoload.php

Penyebab: composer install belum dijalankan (folder vendor belum ada). Atasi: jalankan composer install sampai selesai. Jangan menjalankan serve sebelum langkah ini beres.

ERROR 2002 (HY000): Can't connect to local MySQL server through socket

Penyebab: MySQL belum berjalan (DBngin belum di-start) atau client mencari socket yang salah. Atasi: start MySQL di DBngin, lalu hubungkan lewat jaringan:

mysql -h 127.0.0.1 -u root

bootstrap/cache directory must be present and writable

Penyebab: folder bootstrap/cache (dan sebagian storage) tidak ikut saat ekstrak. Atasi dari folder project:

mkdir -p bootstrap/cache storage/framework/cache storage/framework/sessions storage/framework/views storage/logs
php artisan key:generate

Access denied for user 'root'@'localhost'

Penyebab: password root DBngin berbeda dari .env. Atasi: samakan DB_USERNAME/DB_PASSWORD di .env, lalu jalankan php artisan config:clear.

Halaman tidak berubah setelah mengubah .env

Jalankan php artisan config:clear, lalu muat ulang halaman.

7. Reset dan Backup

Reset data ke kondisi awal seed

php artisan migrate:fresh --seed

Perintah ini MENGHAPUS semua tabel dan mengisinya kembali dari seeder (mengikuti DEMO_DATA di .env). Gunakan hanya bila mau mulai bersih.

Backup database

mysqldump -h 127.0.0.1 -u root mycoffee > backup-mycoffee-$(date +%F).sql

Memulihkan:

mysql -h 127.0.0.1 -u root mycoffee < backup-mycoffee-2026-10-21.sql

Backup juga folder public/images dan file .env agar pemulihan lengkap.

8. Catatan Jujur (Keterbatasan Versi Ini)

  • QRIS masih dummy. Kotak QR di POS hanya contoh tampilan berlabel jelas, bukan kode pembayaran asli; tidak ada integrasi payment gateway. Pembayaran QRIS dianggap pas.
  • Pratinjau versi 4 bersifat static. Multi Cabang, Aplikasi Pelanggan, Payment Gateway Live, Integrasi Akuntansi, dan Ramalan Penjualan baru tampilan "Segera Hadir" tanpa fungsi.
  • Markup harga ojol belum ada. Kanal GoFood/GrabFood tercatat terpisah di laporan, tetapi harganya sama dengan dine-in.
  • Data demo. Kontak, alamat, harga, akun, dan 15 transaksi contoh adalah dummy. Matikan dengan DEMO_DATA=false sebelum migrate --seed; ganti semua kredensial bawaan sebelum dipakai bisnis beneran.
  • Satu toko, satu server lokal. Aplikasi berjalan di satu komputer (Mac + Herd); perangkat lain di jaringan lokal yang sama dapat membukanya lewat alamat IP komputer itu.
